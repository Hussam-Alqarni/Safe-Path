# تشغيل التطبيق على اللابتوب
# Running Safe Path on a laptop

أسرع طريق: **المتصفح**. لا يحتاج محاكي أندرويد ولا مفتاح خرائط ولا خادماً.

## ١. المتطلبات

| | |
|---|---|
| **Flutter** | ٣٫٢٧ أو أحدث. تم التحقق على **3.35.5** (Dart 3.9.2) |
| **Git** | لجلب الكود |

```bash

```

## ٣. التشغيل على المتصفح — الأسرع

```bash
flutter run -d chrome
```

إن لم يجد Chrome:

```bash
flutter devices          # يعرض ما هو متاح
flutter run -d edge      # أو
flutter run -d web-server --web-port 8123   # ثم افتح http://localhost:8123
```

`web-server` هو الخيار الذي يعمل دائماً: لا يحتاج Flutter أن يعرف مكان
متصفحك، فهو يخدم الصفحة وأنت تفتحها بنفسك. **جُرّب هذا المسار وتم التحقق
منه.**

إن أردت `-d chrome` ولم يظهر، دُلّ Flutter على المتصفح:

```bash
# macOS
export CHROME_EXECUTABLE="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"

# Windows (PowerShell)
$env:CHROME_EXECUTABLE="C:\Program Files\Google\Chrome\Application\chrome.exe"

# Linux
export CHROME_EXECUTABLE=$(which google-chrome || which chromium)
```

يبدأ التطبيق في **وضع العرض** مباشرة: أسطول محاكى، خريطة مرسومة داخلياً،
ومدرسة كاملة في جدة. لا مفتاح، لا خادم، لا عتاد.

### اختصارات أثناء التشغيل

| المفتاح | ماذا يفعل |
|---|---|
| `r` | إعادة تحميل ساخنة — تُبقي حالة التطبيق |
| `R` | إعادة تشغيل كاملة — تصفّر الحالة |
| `q` | إنهاء |

## ٤. جولة العرض — بالترتيب

بعد التشغيل، بدّل الأدوار من **أيقونة تبديل الدور** أعلى اليمين.

**١. المطوّر ← «ابدأ الرحلة»**
الحافلة تتحرك على الخريطة، الطلاب يصعدون تلقائياً، والإشعارات تُرسل.

**٢. ولي الأمر**
شاهد أبناءه فقط، مسار اليوم لحظة بلحظة، والخريطة المباشرة.
جرّب **«الإبلاغ عن غياب»** — ستُتخطّى المحطة ويُعاد رسم المسار أمامك.

**٣. السائق**
اضغط **«الملاحة»** لواجهة القيادة بملء الشاشة.
جرّب **«تحضير يدوي»** لطالب — سيصل ولي الأمر إشعار يوضّح أنه يدوي بدون
بطاقة، مع زر اعتراض.
جرّب **زر الاستغاثة** — بضغط مستمر ثانيتين.

**٤. المطوّر ← «محاكاة طالب متروك»**
ثم عُد للسائق و**أنهِ الرحلة**. سترى التنبيه الحرج يصل للإدارة ولولي الأمر
في اللحظة نفسها. هذه هي اللحظة التي تُظهر قيمة المشروع.

**٥. إدارة المدرسة**
لوحة التحكم بالرسوم البيانية. وسّع نافذة المتصفح لترى التخطيط ينتقل
لعمودين.

**٦. موظف المدرسة**
قارئ بوابة المدرسة ومحاكاة تمرير بطاقة.

## ٥. حدود المتصفح — اقرأها قبل أن تستغرب

| الميزة | على المتصفح | الحل |
|---|---|---|
| **خرائط جوجل الحقيقية** | تعمل بعد إضافة المفتاح (خطوة ٦) | بدونه يعمل المحرّك الداخلي |
| **الروابط المختصرة** `maps.app.goo.gl` | **لا تعمل** — المتصفح يمنع الطلب لنطاق آخر (CORS) | استخدم رابطاً كاملاً `google.com/maps/...` أو شغّل على أندرويد |
| **قراءة NFC** | غير مدعومة | تحتاج جهازاً حقيقياً |
| **الاهتزاز عند الاستغاثة** | غير مدعوم | الزر يعمل، بلا اهتزاز |

لتجربة تحديد المنزل على المتصفح، الصق رابطاً كاملاً مثل:

```
https://www.google.com/maps/place/Al+Rawdah/@21.5602,39.1553,17z
```

أو إحداثيات مباشرة: `21.5602, 39.1553`

## ٦. تفعيل خرائط جوجل الحقيقية (اختياري)

**على المتصفح:** افتح `web/index.html` وأزل التعليق عن السطر، وضع مفتاحك:

```html
<script src="https://maps.googleapis.com/maps/api/js?key=YOUR_KEY"></script>
```

ثم شغّل بالمفتاح نفسه:

```bash
flutter run -d chrome --dart-define=GOOGLE_MAPS_API_KEY=YOUR_KEY
```

> التطبيق يقرّر المحرّك من `--dart-define`: بمفتاح ← خرائط جوجل، بدونه ←
> المحرّك الداخلي. لذلك يلزم تمريره في الطرفين، الويب والـ dart-define.

للأندرويد وiOS: [`docs/SETUP.md`](SETUP.md).

## ٧. التشغيل على أندرويد (لتجربة خرائط جوجل والعتاد لاحقاً)

يتطلب Android Studio ومحاكياً أو جهازاً موصولاً.

```bash
# ضع المفتاح مرة واحدة (الملف مُستثنى من git)
echo "MAPS_API_KEY=YOUR_KEY" >> android/local.properties

flutter devices
flutter run -d <device-id> --dart-define=GOOGLE_MAPS_API_KEY=YOUR_KEY
```

## ٨. سطح المكتب — غير مدعوم حالياً

حزمة `google_maps_flutter` تدعم أندرويد وiOS والويب فقط، فلا يوجد
مجلد `windows/` أو `macos/` أو `linux/` في المشروع.

الويب هو البديل العملي على اللابتوب، ويعرض التطبيق نفسه بالكامل.

## ١٠. حين لا يعمل شيء

| العَرَض | السبب الغالب | الحل |
|---|---|---|
| `command not found: flutter` | Flutter ليس في PATH | راجع دليل التثبيت |
| `No devices found` أو لا يظهر Chrome | Flutter لا يجد المتصفح في PATH | صدّر مساره ثم أعد المحاولة (أمثلة أدناه) |
| شاشة بيضاء طويلة أول مرة | الويب يبني CanvasKit | انتظر؛ التشغيل الثاني أسرع |
| `Waiting for another flutter command` | عملية سابقة معلّقة | احذف `~/.flutter_tool_state` أو أعد التشغيل |
| فشل `pub get` | شبكة أو وكيل | `flutter pub get` مجدداً، أو اضبط الوكيل |
| `flutter run -d linux` يفشل | المشروع لا يحتوي مجلد سطح مكتب | استخدم المتصفح — القسم ٨ |
| الخريطة رمادية بعد إضافة المفتاح | المفتاح مقيّد أو Maps JS API غير مفعّل | فعّل **Maps JavaScript API** في Google Cloud |
